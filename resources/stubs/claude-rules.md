# OI Laravel Documentation

Use the `oi-laravel-documentation` package to build a markdown-based documentation site with
auto-generated navigation and full-text search. Content lives under `docs_path`
(default `resources/markdown/docs/`): markdown pages with YAML frontmatter, `meta.json` per
section, and `_index.md` section homepages. Navigation (`navigation.json`) and search
(`search-index.json`) are generated by `doc:gen-nav` and `doc:gen-index` — never hand-edit them.

- IMPORTANT: Activate `oilab-laravel-docs` when writing, editing, or organizing documentation
  pages, sections, `meta.json`, or frontmatter in this application, or when authoring importable
  package docs. After any change to app docs, run `php artisan doc:gen-nav && php artisan doc:gen-index`.
